## 视觉设计

### 1. Slogan 区域

| 属性 | 值 | 说明 |
|------|-----|------|
| 文字 | `t('home_slogan')` | 保持不变 |
| 字号 | 24px / 20px (`text-2xl md:text-3xl`) | 保持 |
| 字重 | 500 (font-medium) | 保持 |
| 颜色 | `text-gray-700 dark:text-gray-200` | 保持 |
| 底部间距 | `mb-3` | 当前 `mb-4`，收紧 4px |

### 2. 卡片网格

| 属性 | 当前值 (#9) | 目标值 (#10) |
|------|------------|--------------|
| 背景 | 彩色渐变 `bg-gradient-to-br ${color}` | 白色 `bg-white` |
| 边框 | 各自不同 | 统一细边框 `border border-gray-100 dark:border-gray-800` |
| 渐变色条 | 保留 | 保留，8px 高度 |
| 圆角 | `rounded-2xl` | 保持 `rounded-2xl` (16px) |
| 间距 | `gap-3` (12px) | `gap-4` (16px) |
| 移动端 | `grid-cols-2` | 保持 |
| 桌面端 | `lg:grid-cols-4` | 保持 |
| 内边距 | `p-4` | 保持 |
| 阴影 | 无 | 无 (保持扁平) |

### 3. 卡片结构

**当前 (#9):**
```tsx
<div className={`rounded-2xl overflow-hidden bg-gradient-to-br ${color} border ${borderColor}`}>
  <div className={`h-2 w-full bg-gradient-to-r ${gradientColors}`} />
  <div className='p-4'>
    {/* content */}
  </div>
</div>
```

**目标 (#10):**
```tsx
<div className='rounded-2xl overflow-hidden bg-white border border-gray-100 dark:border-gray-800'>
  <div className={`h-2 w-full bg-gradient-to-r ${gradientColors}`} />
  <div className='p-4'>
    {/* content */}
  </div>
</div>
```

关键：移除 `${color}` 和 `${borderColor}` 类，使用白色背景和统一细边框。

### 4. 输入框

| 属性 | 当前值 (#9) | 目标值 (#10) |
|------|------------|--------------|
| 高度 | 120px+ (padding 20px) | 48-60px |
| 圆角 | `rounded-[28px]` | `rounded-xl` (12px) |
| 阴影 | 多层复杂阴影 | 无或极轻阴影 `shadow-sm` |
| 边框 | `border border-gray-100` | 保持细边框 |
| 背景 | `bg-white/95` | `bg-white` |
| 内边距 | `p-5` | `p-3` |

### 5. 底部工具栏布局

| 属性 | 当前值 | 目标值 |
|------|--------|--------|
| 工具图标 | 4个（加号、闪电、列表、文件夹） | 2个（上传、布局） |
| 模型选择器 | 胶囊形大按钮 | 保持现有样式但更小 |
| 发送按钮 | 灰色圆形 | 紫色方形 `bg-purple-500` |

**目标底部工具栏结构:**
```
[上传图标] [布局图标]        [模型选择器]        [麦克风] [发送按钮]
  左对齐                      居中               右对齐
```

## 实施任务

1. **卡片样式重构** — 白底+细边框，移除彩色背景
2. **卡片网格间距** — `gap-3` → `gap-4`
3. **Slogan 底部间距** — `mb-4` → `mb-3`
4. **输入框高度收紧** — padding `p-5` → `p-3`，圆角 `rounded-[28px]` → `rounded-xl`，简化阴影
5. **底部工具栏精简** — 减少左侧图标数量，调整布局

## 编码规范

- React 组件使用 TypeScript 严格模式
- Tailwind CSS 使用现有设计系统
- 暗色模式适配：`dark:bg-[#111217]` 等现有 token
- 响应式断点遵循现有配置
